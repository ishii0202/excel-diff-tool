# Excel Diff Tool

2つのExcelファイルを比較して、セルの値・数式とシート構成の差分を日本語で表示し、変更点をExcelレポートにまとめるPython製のコマンドラインツールです。

プログラム本体は `excel_diff.py` の1ファイルで、比較とレポート作成を行います。

途中に行が追加・削除された場合も、前後で一致する行を手がかりに対応付けます。単純に同じセル番地だけを比較する方法より、後続行のずれによる差分を減らせます。

## できること

- セルの値・数式の変更を表示
- 追加・削除された行の空欄以外のセルを表示
- シートの追加・削除・並び替えを検出
- 同梱サンプルを引数なしで実行
- 比較結果を1件1行のExcelレポートとして自動保存
- フィルター・見出し固定・種類ごとの色分けで差分を確認
- 比較元のExcelは変更せず、コマンドラインにも結果を表示

## セットアップ

Python 3.10以上を使用します。Microsoft Excelのインストールは不要です。

別のPCでは、まずPython 3.10以上をインストールし、GitHubからファイルを取得します。Gitを使う場合は次を実行してください。

```bash
git clone https://github.com/ishii0202/excel-diff-tool.git
cd excel-diff-tool
```

Gitを使わない場合は、[GitHubのページ](https://github.com/ishii0202/excel-diff-tool)の「Code」→「Download ZIP」で取得し、展開したフォルダで以降のコマンドを実行できます。以下はプロジェクトのフォルダ内で実行してください。

仮想環境を作成し、依存ライブラリをインストールします。

### macOS / Linux / WSL

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

以降の `python` は、PowerShellでは `.\.venv\Scripts\python.exe` に置き換えて実行できます。仮想環境を有効化するスクリプトの実行許可変更は不要です。

セットアップ後、同梱サンプルを動かすには次を実行します。

```bash
# macOS / Linux / WSL（仮想環境を有効化したターミナル）
python excel_diff.py
```

```powershell
# Windows PowerShell
.\.venv\Scripts\python.exe excel_diff.py
```

手元のファイルを比較するときは、変更前と変更後の `.xlsx` をこの順序で指定します。例えばWindows PowerShellでは次のように実行します。

```powershell
.\.venv\Scripts\python.exe excel_diff.py "C:\Users\ユーザー名\Documents\変更前.xlsx" "C:\Users\ユーザー名\Documents\変更後.xlsx"
```

結果は画面に表示され、Excelレポートもプロジェクト内の `reports/` に保存されます。実際の保存先は実行後に画面へ表示します。

## 使い方

### 同梱サンプルを比較する

```bash
python excel_diff.py
```

`examples/old.xlsx` と `examples/new.xlsx` を比較します。引数なしのサンプルパスは、カレントディレクトリではなくスクリプトの場所を基準に解決します。

レポートはプロジェクト内の `reports/` に `変更点まとめ_日時.xlsx` という名前で自動保存します。実行後に保存先の絶対パスを表示します。

### 手元のExcelを比較する

```bash
python excel_diff.py "変更前.xlsx" "変更後.xlsx"
python excel_diff.py --help
```

引数の順序は「変更前」「変更後」です。ファイル名やフォルダ名に空白がある場合は引用符で囲んでください。

結果は「変更あり」または「変更なし」に続いて、変更の種類、シート名、セル番地、変更前後の値を表示します。空欄は「空欄」と表示します。差分の有無によらず、比較とレポート保存に成功すると終了コードは0です。引数、入力ファイル、レポート保存に問題がある場合は0以外で終了します。

### Excelレポート

レポートの「変更点まとめ」シートでは、1件の変更を次の列で1行にまとめます。

| No. | 種類 | シート名 | 場所 | 変更前 | 変更後 | 内容 |
| ---: | --- | --- | --- | --- | --- | --- |
| 4 | 変更 | 受注一覧 | 新 E10 | 18 | 24 | 値を変更 |

冒頭には比較したファイル名・作成日時・変更件数を記載します。シート構成の差分も同じ一覧に含みます。場所の「新」は変更後、「旧」は変更前のExcel内のセル番地です。値がない場合は空セルにします。行の追加・削除は空欄以外の各セルを1件ずつ記録します。

フィルターで種類やシートを絞り込めます。数式は文字列として表示するため、レポート内では実行されません。変更がない場合も「変更なし」のレポートを作成します。

保存先を変える場合は `--output`（短縮形 `-o`）で `.xlsx` のパスを指定します。保存先のフォルダは必要に応じて作成します。

```bash
python excel_diff.py "変更前.xlsx" "変更後.xlsx" --output "reports/変更点まとめ.xlsx"
python excel_diff.py -o "reports/サンプル比較.xlsx"
```

既定の出力先はスクリプトの場所を基準にした `reports/` です。指定した相対パスは、実行時のカレントディレクトリを基準に解決します。既存ファイルや比較元のファイルには上書きしません。同名ファイルがある場合は、別の名前を指定してください。

レポートには比較対象のセル内容が含まれます。`reports/` はGit管理対象から除外しています。

コマンドラインの表示もテキストに保存できます。

```bash
python excel_diff.py "変更前.xlsx" "変更後.xlsx" > diff.txt
```

## サンプルデータ

サンプルはすべて架空の業務データです。受注一覧・商品マスタ・進行管理を中心に、旧版と新版の間に意図的な変更を用意しています。

数量・納期・ステータス・空欄・数式の変更、途中行の追加と削除、シートの追加・削除・並び替えを試せます。詳しい差分は [サンプルの説明](examples/README.md) を参照してください。

## 比較方法と制約

- 対応する行は、行全体の値と `difflib.SequenceMatcher` により推定します。ID列をキーにした照合ではありません。変更と追加・削除が同じ範囲に重なる場合や、同じ内容の行が多い場合は、意図した行同士が対応しないことがあります。
- 列は同じ列番号で比較します。列の追加・削除・移動や行の並び替えを、独立した操作として識別する機能はありません。
- 値の比較にはPythonの等値判定を使います。数値の `1` と `1.0`、数値の `1` と真偽値の `True` は同じ値として扱います。
- 数式は `=SUM(...)` などの文字列を比較します。計算結果を再計算して比較する機能はありません。
- 書式・色・列幅・行高・コメント・図表・結合状態・非表示状態などは比較対象外です。
- シート名の変更は、旧名のシート削除と新名のシート追加として表示します。追加・削除されたシートのセル内容は個別に列挙しません。
- セル番地は、追加・変更では新版、削除では旧版の位置です。空白行だけの追加・削除は表示しません。
- シート移動は共通シートの相対順序から推定します。同じ並び順に至る操作が複数ある場合、実際に操作したシートを特定できるとは限りません。シート全体での位置が同じでも、共通シート間の相対順序が変わっている場合は、その旨を表示します。
- 対象は通常の `.xlsx` ファイルです。旧形式の `.xls`、パスワードで暗号化されたファイルは対象外です。
- ワークブックと比較用の行データをメモリに読み込むため、大規模なファイルでは時間やメモリを多く使う場合があります。

## 開発・テスト

```bash
python -m unittest discover -s tests -v
```

GitHub Actionsにもテストとサンプル実行を設定しています。Python 3.10 / 3.12 / 3.14のLinux環境と、Python 3.12のWindows環境が対象です。

```text
exceltool/
├── excel_diff.py          # 比較・Excelレポート・CLI
├── requirements.txt      # 依存ライブラリ
├── examples/
│   ├── old.xlsx          # 架空データの旧版
│   ├── new.xlsx          # 架空データの新版
│   └── README.md         # 意図的な差分の説明
├── reports/              # 自動生成レポート（Git対象外）
├── tests/                # 比較処理・レポート・CLIのテスト
└── .github/workflows/    # 自動テスト
```

`.gitignore` で仮想環境、キャッシュ、ローカル設定、作業用バックアップを除外しています。Excelファイルは `examples/old.xlsx` と `examples/new.xlsx` だけをGit管理対象にしています。
