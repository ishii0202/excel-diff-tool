# サンプルExcel

`old.xlsx` は変更前、`new.xlsx` は変更後です。雑貨店向けの受注・商品・業務管理を題材にした架空データで、企業名・担当者名・取引内容はすべてサンプルです。

プロジェクトのルートで `python excel_diff.py` を実行すると、この2ファイルを比較できます。

## 内容

| シート | データ行数 | 内容 |
| --- | ---: | --- |
| 受注一覧 | 各20件 | 顧客、商品、数量、契約単価、金額、納期、状況 |
| 商品マスタ | 各10件 | 標準価格、在庫数、発注点、販売状況 |
| 進行管理 | 各10件 | 作業内容、担当、期限、状態、進捗率 |
| 終了案件 | 旧版のみ4件 | 完了した企画・業務 |
| 新規企画 | 新版のみ5件 | 翌月以降の企画と予算案 |

表はフィルター・見出し固定付きです。日付・数値はExcelの値として保持し、金額は数式で計算しています。受注一覧の単価は契約時点の値なので、商品マスタの標準価格の変更とは連動しません。

## 意図的な差分

旧版のシート順は「受注一覧 → 商品マスタ → 進行管理 → 終了案件」、新版は「受注一覧 → 進行管理 → 商品マスタ → 新規企画」です。

| 種類 | 場所 | 変更前 → 変更後 |
| --- | --- | --- |
| 数量の変更 | 受注一覧 `E10` | 18 → 24 |
| 数式の変更 | 受注一覧 `G13` | `=E13*F13` → `=ROUND(E13*F13,0)` |
| 納期の変更 | 受注一覧 `H14` | 2026/09/11 → 2026/09/15 |
| 状況の変更 | 受注一覧 `I17` | 準備中 → 出荷済 |
| 空欄への追記 | 受注一覧 `J21` | 空欄 → 午前便を希望 |
| 標準価格の変更 | 商品マスタ `D10` | 3,600 → 3,800 |
| 在庫数の変更 | 商品マスタ `E14` | 42 → 68 |
| 販売状況の変更 | 商品マスタ `G16` | 取寄 → 販売終了 |
| 空欄への追記 | 商品マスタ `H17` | 空欄 → 10月版を先行受付 |
| 状態・進捗率の変更 | 進行管理 `F9:G9` | 進行中・80% → 完了・100% |
| 行の追加 | 進行管理 新版11行目 | TK-011「招待メールの原稿」を追加 |
| 行の削除 | 進行管理 旧版12行目 | TK-005「旧カタログの再印刷」を削除 |
| 空欄への追記 | 進行管理 `H14` | 空欄 → サンプル箱を手配 |
| シートの追加 | 新規企画 | 新版の4番目に追加 |
| シートの削除 | 終了案件 | 旧版の4番目を削除 |
| シートの並び替え | 進行管理 | 3番目 → 2番目 |

並び替えは共通シートの相対順序から判定します。このサンプルでは「進行管理」を移動として表示し、「商品マスタ」は順序を維持した側として扱います。

途中行の追加・削除は、それぞれ空欄以外の8セル分の追加・削除として表示されます。TK-004は旧版11行目から新版12行目へずれますが、内容が同じなので変更にはなりません。

## 数式を比較する例

受注一覧 `G13` の計算結果は両方とも28,800円ですが、数式の文字列が異なるため変更として検出します。

一方、数量変更により `G10` の計算結果は64,800円から86,400円へ、`C5` の受注合計は562,750円から584,350円へ変わります。これらのセルは数式自体が同じなので、ツールの変更一覧には出ません。

書式、フィルター、入力規則、条件付き書式の違いは、このツールの比較対象に含まれません。
